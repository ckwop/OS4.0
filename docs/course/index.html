How OS 4.0 is put together

Short narrated lectures, one area of the system each. Press play and listen: the slides show a picture or a piece of real code, and the narration carries the detail. Each lecture ends with questions for a coaching session, and a code tour (.tours/, for VS Code's CodeTour extension) walks through the same code in your editor. On any slide, the Code button (or v) opens the matching step of the tour in VS Code, with this repository open.

Speech uses your browser's own voices; Microsoft Edge's "Natural" voices sound best. Captions and a transcript are a key away (c, t).
